# Пополнение словаря через GigaChat

## Обзор

Скрипт `generate_dictionary.py` использует GigaChat API для генерации слов и добавления их в базу данных.

## Промпт для генерации

Промпт запрашивает у GigaChat:
- Слова для указанного языка и уровня CEFR
- Распределение частей речи: 40% nouns, 30% verbs, 20% adjectives, 10% другие
- Переводы на русский (2-3 варианта)
- Формат ответа: JSON

### Пример промпта:

```
Ты — лингвист-эксперт. Сгенерируй список слов для изучения языка.

Требования:
1. Язык изучения: English (en)
2. Уровень CEFR: A1
3. Количество слов: 30
4. Родной язык пользователя: русский

Для каждого слова укажи:
- lemma — начальная форма слова
- pos — часть речи (noun, verb, adjective, adverb, preposition, pronoun, conjunction)
- cefr_level — уровень (A1)
- translations — массив переводов на русский (2-3 варианта)

Распределение частей речи:
- 40% nouns (существительные)
- 30% verbs (глаголы)
- 20% adjectives (прилагательные)
- 10% другие части речи

Требования к словам:
- Слова должны быть практичными и часто используемыми
- Переводы должны быть точными
- Для глаголов — инфинитив
- Для существительных — единственное число
- Для прилагательных — мужской род (если применимо)

Верни ТОЛЬКО JSON в формате:
{
    "words": [
        {
            "lemma": "слово",
            "pos": "noun",
            "cefr_level": "A1",
            "translations": ["перевод1", "перевод2"]
        }
    ]
}
```

## Использование

### Установка зависимостей

```bash
cd backend
pip install httpx
```

### Запуск

```bash
# Все языки, все уровни (по 30 слов за запрос)
python generate_dictionary.py

# Только английский
python generate_dictionary.py --lang en

# Только уровень A1
python generate_dictionary.py --level A1

# 50 слов за запрос
python generate_dictionary.py --count 50

# Сухой прогон (показать, что будет добавлено, но не добавлять)
python generate_dictionary.py --dry-run

# Комбинация параметров
python generate_dictionary.py --lang en --level A1 --count 50
```

### Параметры

- `--lang` — язык (en, de, es, fr). По умолчанию — все языки
- `--level` — уровень CEFR (A1, A2, B1, B2). По умолчанию — все уровни
- `--count` — количество слов за запрос (по умолчанию 30)
- `--dry-run` — только показать, что будет добавлено, без записи в БД

## Примеры использования

### 1. Populate all dictionaries

```bash
python generate_dictionary.py
```

Это создаст:
- 4 языка × 4 уровня × 30 слов = 480 слов

### 2. Populate only English A1

```bash
python generate_dictionary.py --lang en --level A1
```

Это создаст 30 английских слов уровня A1.

### 3. Test before adding

```bash
python generate_dictionary.py --dry-run
```

Это покажет, какие слова будут добавлены, но не запишет их в БД.

### 4. Generate more words

```bash
python generate_dictionary.py --count 100
```

Это создаст 100 слов за один запрос (вместо 30 по умолчанию).

## Структура данных

### Таблица `dictionaries`

```sql
id              UUID PRIMARY KEY
target_lang     VARCHAR(10)      -- en, de, es, fr
lemma           VARCHAR(100)     -- начальная форма слова
pos             VARCHAR(20)      -- часть речи
cefr_level      VARCHAR(5)       -- A1, A2, B1, B2
```

### Таблица `dictionary_translations`

```sql
id              UUID PRIMARY KEY
dictionary_id   UUID FK          -- ссылка на dictionaries
lang            VARCHAR(10)      -- язык перевода (ru)
translations    JSONB            -- массив переводов
```

## Уникальность

Скрипт проверяет уникальность по комбинации:
- `lemma` + `pos` + `target_lang`

Если слово уже существует, оно пропускается.

## Логирование

Скрипт выводит:
- Прогресс генерации для каждого языка/уровня
- Количество добавленных/пропущенных слов
- Ошибки (если есть)

## Рекомендации

1. **Начните с dry-run** — проверьте, какие слова будут добавлены
2. **Генерируйте по одному языку** — для лучшего контроля
3. **Используйте --count 50** — для большего количества слов за раз
4. **Проверяйте дубликаты** — скрипт автоматически их пропускает
5. **Сохраняйте логи** — для отслеживания прогресса

## Ошибки

### Ошибка получения токена

```
❌ Ошибка получения токена: 401 Unauthorized
```

**Решение:** Проверьте `GIGACHAT_CREDENTIALS` в `.env`

### Ошибка подключения к БД

```
❌ Ошибка подключения к базе данных
```

**Решение:** Проверьте `DATABASE_URL` в `.env`

### Ошибка API

```
Ошибка API: 429 - Rate limit exceeded
```

**Решение:** Подождите несколько минут и попробуйте снова

## Статистика

После запуска проверьте количество слов в админке:

```
http://localhost:8000/admin
```

Таблица `dictionaries` должна содержать новые слова.
