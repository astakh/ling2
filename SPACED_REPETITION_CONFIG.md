# Параметры повторения слов (Spaced Repetition)

## Обзор

Система использует алгоритм интервального повторения для эффективного запоминания слов. Параметры настраиваются через переменные окружения в файле `backend/.env`.

## Переменные окружения

### MAX_LESSONS

**Описание:** Максимальное количество уроков в день (лимит для пользователя)

**Тип:** `int`

**По умолчанию:** `100`

**Пример:**
```env
MAX_LESSONS=100
```

**Как работает:**
- Определяет максимальное значение слайдера "Уроков в день" в профиле пользователя
- Пользователь может выбрать значение от 1 до MAX_LESSONS
- Администратор может изменить этот лимит в файле `.env`

### WORDS_PER_LESSON

**Описание:** Количество слов в уроке (по умолчанию)

**Тип:** `int`

**По умолчанию:** `5`

**Пример:**
```env
WORDS_PER_LESSON=5
```

**Как работает:**
- При создании нового урока система добавляет WORDS_PER_LESSON новых слов
- Пользователь может изменить это значение в профиле (от 1 до 20)
- Рекомендуемое значение: 5-7 слов для оптимального запоминания

### REPETITION_INTERVALS

**Описание:** Интервалы повторения в уроках (через запятую)

**Тип:** `str` (список чисел через запятую)

**По умолчанию:** `1,2,4,7,14,21,30,45,60,90`

**Пример:**
```env
REPETITION_INTERVALS=1,2,4,7,14,21,30,45,60,90
```

**Как работает:**
- Каждое значение - количество уроков до следующего повторения
- Индекс в списке соответствует `stage` слова
- Пример для `stage=3`: слово повторится через 7 уроков

**Таблица интервалов (по умолчанию):**

| Stage | Интервал (уроков) | Описание |
|-------|-------------------|----------|
| 0     | 1                 | Повторить в следующем уроке |
| 1     | 2                 | Повторить через 2 урока |
| 2     | 4                 | Повторить через 4 урока |
| 3     | 7                 | Повторить через неделю |
| 4     | 14                | Повторить через 2 недели |
| 5     | 21                | Повторить через 3 недели |
| 6     | 30                | Повторить через месяц |
| 7     | 45                | Повторить через 1.5 месяца |
| 8     | 60                | Повторить через 2 месяца |
| 9     | 90                | Повторить через 3 месяца |

## Примеры настройки

### Лёгкий режим (для начинающих)

```env
MAX_LESSONS=5
WORDS_PER_LESSON=3
REPETITION_INTERVALS=1,2,3,5,7,10,14,21,30,45
```

### Стандартный режим (рекомендуется)

```env
MAX_LESSONS=10
WORDS_PER_LESSON=5
REPETITION_INTERVALS=1,2,4,7,14,21,30,45,60,90
```

### Интенсивный режим (для продвинутых)

```env
MAX_LESSONS=20
WORDS_PER_LESSON=10
REPETITION_INTERVALS=1,1,2,3,5,7,10,14,21,30
```

## Как изменить параметры

1. Откройте файл `backend/.env`
2. Найдите секцию "Spaced repetition parameters"
3. Измените значения переменных
4. Перезапустите backend:
   ```bash
   # Остановите текущий процесс (Ctrl+C)
   python main.py
   ```
5. Проверьте логи - вы должны увидеть:
   ```
   Spaced Repetition Configuration:
     MAX_LESSONS: 100
     WORDS_PER_LESSON: 5
     REPETITION_INTERVALS: 1,2,4,7,14,21,30,45,60,90
   ```

## Логика работы

### При создании урока

```python
# Из config.py
words_per_lesson = settings.WORDS_PER_LESSON  # 5 по умолчанию

# Добавляем новые слова
new_words = await get_new_words(db, profile_id, target_lang, words_per_lesson, ...)
```

### При проверке дневного лимита

```python
# Из config.py
max_daily_lessons = settings.MAX_LESSONS  # 100 по умолчанию

# Проверяем, не превышен ли лимит
if today_lessons_count >= profile.daily_lesson_limit:
    raise HTTPException(status_code=429, detail="Daily lesson limit reached")
```

### При проверке перевода

```python
# Из config.py
intervals = [int(x) for x in settings.REPETITION_INTERVALS.split(",")]
# [1, 2, 4, 7, 14, 21, 30, 45, 60, 90]

# При правильном переводе
if is_correct:
    user_word.stage = min(user_word.stage + 1, 10)  # Максимум stage = 10
    interval = intervals[min(user_word.stage, len(intervals) - 1)]
    user_word.due_lesson_number = current_lesson + interval

# При неправильном переводе
else:
    user_word.stage = max(user_word.stage - 1, 0)
    interval = intervals[min(user_word.stage, len(intervals) - 1)]
    user_word.due_lesson_number = current_lesson + interval
```

## Рекомендации

### Для начинающих
- **MAX_LESSONS:** 3-5 (ограничение уроков в день)
- **WORDS_PER_LESSON:** 3-5
- **REPETITION_INTERVALS:** Более короткие интервалы (1,2,3,5,7,10,14,21,30)

### Для средних пользователей
- **MAX_LESSONS:** 10
- **WORDS_PER_LESSON:** 5-7
- **REPETITION_INTERVALS:** Стандартные (1,2,4,7,14,21,30,45,60,90)

### Для продвинутых
- **MAX_LESSONS:** 15-20
- **WORDS_PER_LESSON:** 7-10
- **REPETITION_INTERVALS:** Более длинные интервалы (2,4,7,14,21,30,45,60,90,120)

## Мониторинг

При запуске backend в логах отображаются текущие параметры:

## Примечания

- Изменение параметров применяется только к **новым** урокам
- Уже созданные уроки используют параметры, которые были активны на момент их создания
- Пользователь может изменить `WORDS_PER_LESSON` в профиле (это переопределяет значение из .env)
- `MAX_LESSONS` и `REPETITION_INTERVALS` применяются глобально для всех пользователей

## Технические детали

### Формат хранения в БД

**Таблица `user_words`:**
```sql
stage               INTEGER DEFAULT 0
due_lesson_number   INTEGER DEFAULT 1
```

**Таблица `user_language_profiles`:**
```sql
words_per_lesson_limit  INTEGER DEFAULT 5
```

### Ограничения

- `MAX_LESSONS` должен быть >= 1 (лимит уроков в день для пользователя)
- `WORDS_PER_LESSON` должен быть от 1 до 20
- `REPETITION_INTERVALS` должен содержать минимум 1 значение
- Все значения в `REPETITION_INTERVALS` должны быть положительными целыми числами

## Заключение

Параметры повторения слов позволяют гибко настраивать систему под разные уровни подготовки и предпочтения пользователей. Параметр `MAX_LESSONS` определяет максимальное количество уроков в день, которое может установить пользователь в своём профиле. Рекомендуемые значения обеспечивают оптимальный баланс между эффективностью запоминания и когнитивной нагрузкой.
