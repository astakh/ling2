# Обновление дизайна: Современный и лаконичный стиль

## Обзор

Дизайн приложения полностью переработан в современном минималистичном стиле. Убраны яркие градиенты и эмодзи, добавлено больше воздуха, улучшена типографика и цветовая схема.

## Основные изменения

### 1. Цветовая схема

**Было:**
- Яркие градиенты (indigo → purple)
- Множество цветов для разных элементов
- Эмодзи для иконок

**Стало:**
- Нейтральная палитра (gray-50, gray-900)
- Один акцентный цвет для интерактивных элементов
- Современные иконки из lucide-react
- Минимум цвета, максимум контраста

### 2. Типографика

**Улучшения:**
- Более чёткая иерархия шрифтов
- Увеличены отступы между элементами
- Улучшена читаемость текста
- Добавлены font-feature-settings для современных шрифтов

### 3. Компоненты

#### Карточки
```css
.card {
  @apply bg-white rounded-2xl border border-gray-200 shadow-sm;
}
```
- Убраны градиенты
- Добавлены тонкие границы
- Минимальные тени
- Скруглённые углы (rounded-2xl)

#### Кнопки
```css
.btn-primary {
  @apply bg-gray-900 text-white px-6 py-3 rounded-xl font-medium 
         hover:bg-gray-800 active:bg-gray-950 transition-all duration-200;
}

.btn-secondary {
  @apply bg-white text-gray-900 px-6 py-3 rounded-xl font-medium border border-gray-200
         hover:bg-gray-50 active:bg-gray-100 transition-all duration-200;
}
```
- Плоский дизайн без градиентов
- Чёткие состояния hover/active
- Плавные переходы (duration-200)

#### Поля ввода
```css
.input {
  @apply w-full px-4 py-3 bg-white border border-gray-200 rounded-xl
         focus:outline-none focus:ring-2 focus:ring-gray-900 focus:border-transparent;
}
```
- Минималистичный дизайн
- Чёткий фокус-стейт
- Убраны лишние эффекты

### 4. Страницы

#### Dashboard
- Убраны градиентные фоны
- Карточки статистики с минимальным дизайном
- Чистая типографика
- Больше whitespace

#### Lesson
- Упрощён интерфейс урока
- Минималистичные карточки слов
- Чистые индикаторы прогресса
- Убраны лишние градиенты

#### Profile
- Современный дизайн настроек
- Чистые слайдеры
- Минималистичные карточки уровней
- Улучшена читаемость

#### Vocabulary
- Простой список слов
- Минималистичные фильтры
- Чистое отображение прогресса
- Убраны лишние эффекты

#### Onboarding
- Современный процесс регистрации
- Чистые карточки выбора
- Минималистичные кнопки
- Убраны эмодзи

#### LessonComplete
- Простой экран завершения
- Минималистичная статистика
- Чистая анимация конфетти (серые цвета)
- Убраны яркие цвета

### 5. Анимации

**Улучшения:**
- Более плавные переходы
- Меньше движений
- Фокус на содержании, а не на эффектах
- Длительность анимаций: 200-300ms

### 6. Отступы и spacing

**Изменения:**
- Увеличены отступы между секциями (py-12)
- Больше воздуха внутри карточек (p-6)
- Улучшена визуальная иерархия
- Добавлены разделители

## Преимущества нового дизайна

✅ **Современность** - соответствует текущим трендам UI/UX  
✅ **Читаемость** - улучшена благодаря минимализму  
✅ **Профессионализм** - выглядит более серьёзно и качественно  
✅ **Фокус на контенте** - убраны отвлекающие элементы  
✅ **Доступность** - улучшен контраст и читаемость  
✅ **Производительность** - меньше градиентов и эффектов  

## Цветовая палитра

### Основные цвета
- **Фон:** gray-50 (#f9fafb)
- **Текст:** gray-900 (#111827)
- **Карточки:** white (#ffffff)
- **Границы:** gray-200 (#e5e7eb)

### Акцентные цвета
- **Успех:** green-600 (#16a34a)
- **Ошибка:** red-600 (#dc2626)
- **Инфо:** blue-600 (#2563eb)
- **Предупреждение:** yellow-600 (#ca8a04)

### Нейтральные цвета
- **Текст основной:** gray-900 (#111827)
- **Текст вторичный:** gray-500 (#6b7280)
- **Текст третичный:** gray-400 (#9ca3af)

## Типографика

### Шрифты
- **Заголовки:** font-bold, text-3xl/text-2xl
- **Основной текст:** font-medium, text-base
- **Вспомогательный текст:** text-sm, text-gray-500
- **Мелкий текст:** text-xs, text-gray-400

### Иерархия
1. **H1:** text-3xl font-bold (заголовки страниц)
2. **H2:** text-2xl font-bold (заголовки секций)
3. **H3:** text-lg font-semibold (заголовки карточек)
4. **Body:** text-base font-medium (основной текст)
5. **Caption:** text-sm text-gray-500 (подписи)
6. **Small:** text-xs text-gray-400 (мелкий текст)

## Примеры использования

### Карточка статистики
```tsx
<div className="card p-6">
  <div className="flex items-center gap-3 mb-2">
    <Flame className="w-5 h-5 text-orange-500" />
    <span className="text-sm text-gray-500">Стрик</span>
  </div>
  <div className="text-3xl font-bold text-gray-900">{stats?.current_streak || 0}</div>
  <div className="text-xs text-gray-400 mt-1">дней подряд</div>
</div>
```

### Кнопка действия
```tsx
<button className="btn-primary w-full">
  Начать урок
</button>
```

### Поле ввода
```tsx
<input
  type="text"
  placeholder="Введите текст..."
  className="input"
/>
```
