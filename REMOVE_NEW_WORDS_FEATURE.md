# Функция удаления слов из списка новых слов

## Описание

На экране "Новые слова для изучения" пользователь может пометить слово как выученное, если он уже знает его. Слово будет добавлено в `user_words` со статусом `learned` и удалено из списка для изучения.

## Как это работает

### UI изменения

1. **Кнопка удаления** - на каждом слове появилась иконка корзины (🗑️) в правом верхнем углу
2. **Визуальная индикация** - удалённые слова становятся полупрозрачными, текст зачёркивается
3. **Статус** - под удалённым словом появляется надпись "Помечено как выученное" ✓
4. **Счётчик** - внизу страницы показывается количество помеченных слов
5. **Кнопка "Начать урок"** - показывает количество оставшихся слов для изучения

### Логика работы

1. Пользователь нажимает на иконку корзины на слове
2. Вызывается API `markWordLearned(profileId, dictionaryId)`
3. Слово добавляется в `user_words` со статусом `learned`
4. Слово визуально помечается как удалённое
5. Счётчик обновляется
6. Кнопка "Начать урок" показывает обновлённое количество слов

## Технические детали

### Frontend

#### Новые состояния

```typescript
const [removedNewWords, setRemovedNewWords] = useState<Set<string>>(new Set());
```

#### Новая функция

```typescript
const handleRemoveNewWord = async (dictionaryId: string) => {
  if (!profile) return;
  
  console.log('[Lesson] Removing new word and marking as learned:', dictionaryId);
  
  try {
    await markWordLearned(profile.id, dictionaryId);
    console.log('[Lesson] Word marked as learned successfully');
    
    // Update local state
    setRemovedNewWords(prev => new Set([...prev, dictionaryId]));
  } catch (error) {
    console.error('[Lesson] Failed to remove word:', error);
  }
};
```

#### UI изменения

- Добавлена иконка `Trash2` из `lucide-react`
- Кнопка удаления с hover-эффектом
- Визуальная индикация удалённых слов (прозрачность, зачёркивание)
- Счётчик удалённых слов
- Обновлённая кнопка "Начать урок"

### Backend

Используется существующий API эндпоинт:

```python
POST /api/words/mark-learned
{
  "profile_id": "xxx",
  "dictionary_id": "xxx"
}
```

Этот эндпоинт:
- Устанавливает `status = "learned"` для слова
- Устанавливает `stage = 10` (максимальный уровень)
- Устанавливает `due_lesson_number = 999999` (больше не будет повторяться)

## Примеры использования

### Сценарий 1: Пользователь знает некоторые слова

1. На экране "Новые слова для изучения" отображается 5 слов
2. Пользователь знает 2 из них
3. Нажимает на иконку корзины для этих 2 слов
4. Слова помечаются как выученные
5. Счётчик показывает "Помечено как выученные: 2 из 5"
6. Кнопка "Начать урок" показывает "Начать урок → (3 слов для изучения)"
7. Пользователь нажимает "Начать урок"
8. В уроке будут только 3 слова для изучения (не 5)

### Сценарий 2: Пользователь знает все слова

1. На экране отображается 5 слов
2. Пользователь помечает все 5 как выученные
3. Счётчик показывает "Помечено как выученные: 5 из 5"
4. Кнопка "Начать урок" показывает "Начать урок → (0 слов для изучения)"
5. Пользователь нажимает "Начать урок"
6. Урок начинается без новых слов (только повторение)

### Сценарий 3: Пользователь не удаляет слова

1. На экране отображается 5 слов
2. Пользователь не нажимает на иконки корзины
3. Счётчик не отображается
4. Кнопка "Начать урок" показывает "Начать урок →"
5. Пользователь нажимает "Начать урок"
6. В уроке будут все 5 слов для изучения

## Преимущества

✅ **Экономия времени** - пользователь не тратит время на изучение знакомых слов  
✅ **Персонализация** - каждый пользователь может настроить урок под себя  
✅ **Мотивация** - пользователь чувствует контроль над процессом обучения  
✅ **Эффективность** - фокус на действительно новых словах  
✅ **Гибкость** - можно пометить любое количество слов как выученные
