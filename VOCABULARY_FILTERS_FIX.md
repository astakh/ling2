# Исправление фильтров и пагинации на странице "Мои слова"

## Проблема

На странице "Мои слова" были следующие проблемы:
1. Фильтр "Выученные" показывал только 10 слов (ограничение пагинации)
2. Присутствовал лишний фильтр "Активные"
3. Фильтр "Изучаю" показывал только слова с stage < 5, а не все активные слова

## Решение

### Изменения в фильтрах

**Было:**
- Все
- Активные (status === 'active')
- Изучаю (status === 'active' && stage < 5)
- Выученные (status === 'learned')

**Стало:**
- Все (все слова)
- Изучаю (status === 'active') - все активные слова
- Выученные (status === 'learned') - все выученные слова

### Изменения в коде

#### 1. Тип фильтра

```typescript
// Было
const [filter, setFilter] = useState<'all' | 'active' | 'learning' | 'learned'>('all');

// Стало
const [filter, setFilter] = useState<'all' | 'learning' | 'learned'>('all');
```

#### 2. Логика фильтрации

```typescript
// Было
const filtered = wordsWithDict.filter((w: any) => {
  const matchesSearch = w.dict.lemma.toLowerCase().includes(search.toLowerCase()) ||
    (w.dict.translations['ru'] || []).some((t: string) => t.toLowerCase().includes(search.toLowerCase()));
  
  if (filter === 'active') return matchesSearch && w.status === 'active';
  if (filter === 'learning') return matchesSearch && w.status === 'active' && w.stage < 5;
  if (filter === 'learned') return matchesSearch && w.status === 'learned';
  return matchesSearch;
});

// Стало
const filtered = wordsWithDict.filter((w: any) => {
  const matchesSearch = w.dict.lemma.toLowerCase().includes(search.toLowerCase()) ||
    (w.dict.translations['ru'] || []).some((t: string) => t.toLowerCase().includes(search.toLowerCase()));
  
  if (filter === 'learning') return matchesSearch && w.status === 'active';
  if (filter === 'learned') return matchesSearch && w.status === 'learned';
  return matchesSearch;
});
```

#### 3. UI фильтров

```typescript
// Было
{(['all', 'active', 'learning', 'learned'] as const).map(f => (
  <button key={f} onClick={() => setFilter(f)}>
    {f === 'all' ? 'Все' : f === 'active' ? 'Активные' : f === 'learning' ? 'Изучаю' : 'Выученные'}
  </button>
))}

// Стало
{(['all', 'learning', 'learned'] as const).map(f => (
  <button key={f} onClick={() => setFilter(f)}>
    {f === 'all' ? 'Все' : f === 'learning' ? 'Изучаю' : 'Выученные'}
  </button>
))}
```

## Пагинация

Пагинация уже была реализована и работает корректно для всех фильтров:

```typescript
// Пагинация
const totalPages = Math.ceil(filtered.length / itemsPerPage);
const startIndex = (currentPage - 1) * itemsPerPage;
const endIndex = startIndex + itemsPerPage;
const paginatedWords = filtered.slice(startIndex, endIndex);

// Сброс страницы при изменении фильтра или поиска
useEffect(() => {
  setCurrentPage(1);
}, [search, filter]);
```

### Параметры пагинации

- **itemsPerPage:** 20 слов на странице
- **totalPages:** вычисляется автоматически на основе отфильтрованных слов
- **Навигация:** кнопки "Назад" и "Вперёд"
- **Номера страниц:** отображается до 5 номеров страниц с умной логикой

```sql
FROM user_words 
WHERE user_language_profile_id = 'xxx'
GROUP BY status;

-- Должно быть:
-- active: X слов
-- learned: Y слов
-- ignored: Z слов

-- Проверить пагинацию
SELECT * FROM user_words 
WHERE user_language_profile_id = 'xxx'
AND status = 'learned'
LIMIT 20 OFFSET 0;  -- Страница 1

SELECT * FROM user_words 
WHERE user_language_profile_id = 'xxx'
AND status = 'learned'
LIMIT 20 OFFSET 20;  -- Страница 2
```
