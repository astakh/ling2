# Архитектура мультиязычной системы со специализированными словарями

## Обзор

Перестройка проекта для поддержки:
- Нескольких языков изучения одновременно
- Специализированных словарей (general, IT, business, и т.д.)
- Переключения между словарями без потери прогресса
- Отдельных страниц для каждого языка

## Структура базы данных

### 1. Таблица `dictionary_categories` (НОВАЯ)

Описание доступных категорий словарей:

```sql
CREATE TABLE dictionary_categories (
    id VARCHAR(36) PRIMARY KEY,
    name VARCHAR(100) NOT NULL,           -- "Общий", "IT", "Бизнес"
    description TEXT,                     -- Описание категории
    icon VARCHAR(50),                     -- Иконка (emoji или название)
    target_langs JSONB,                   -- Для каких языков доступна ["en", "de"]
    created_at TIMESTAMP DEFAULT NOW()
);
```

Добавление поля `dictionary_category`:

## Логика работы

### Добавление нового языка

1. Пользователь нажимает "Добавить язык" на Dashboard
2. Выбирает язык (en, de, es, fr)
3. Выбирает уровень CEFR (A1, A2, B1, B2)
4. Выбирает словарь (карточки с описанием и количеством слов)
5. Настраивает количество слов в уроке
6. Настраивает количество уроков в день
7. Создаётся `user_language_profile` с выбранными параметрами

### Выбор словаря

1. Backend возвращает список доступных категорий для выбранного языка
2. Для каждой категории показывается:
   - Название
   - Описание
   - Иконка
   - Количество слов для данного языка
3. Пользователь выбирает категорию
4. Категория сохраняется в `user_language_profiles.dictionary_category`

### Переключение словаря

1. Пользователь открывает профиль языка
2. Нажимает "Изменить словарь"
3. Выбирает новый словарь
4. Backend обновляет `dictionary_category` в профиле
5. Уже изученные слова остаются в `user_words` (не удаляются)
6. Новые слова будут браться из новой категории

### Получение новых слов для урока

```python
async def get_new_words(db, profile_id, target_lang, limit, exclude_ids, cefr_level, category):
    # Получаем уже изученные слова
    learned_ids = get_user_word_ids(profile_id) | exclude_ids
    
    # Ищем новые слова в указанной категории
    query = select(Dictionary).where(
        Dictionary.target_lang == target_lang,
        Dictionary.category == category,  # ← Фильтр по категории
        Dictionary.cefr_level.in_(allowed_levels),
        ~Dictionary.id.in_(learned_ids)
    )
    
    return query.limit(limit).all()
```

## Риски и решения

### Риск 1: Производительность при большом количестве слов
**Решение:** Индексы по `(target_lang, category)`, пагинация в API

### Риск 2: Конфликт слов между словарями
**Решение:** Уникальность по `(lemma, pos, target_lang, category)`

### Риск 3: Миграция существующих данных
**Решение:** Все существующие слова получают `category = 'general'`

### Риск 4: Сложность UI
**Решение:** Пошаговый мастер добавления языка, понятные карточки
